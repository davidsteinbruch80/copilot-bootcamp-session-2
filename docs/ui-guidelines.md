# UI Guidelines - TODO App

## Component Framework
- Use Material-UI components for consistent design system
- Follow Material Design principles for layout and interaction

## Color Palette
- Primary: #1976d2 (blue)
- Secondary: #dc004e (pink)
- Success: #388e3c (green)
- Warning: #f57c00 (orange)
- Error: #d32f2f (red)
- Background: #f5f5f5 (light gray)

## Button Styles
- Primary actions: Material-UI contained buttons
- Secondary actions: Material-UI outlined buttons
- Destructive actions: Red contained buttons
- Icon buttons for compact spaces

## Typography
- Use Material-UI default typography scale
- Roboto font family
- Clear hierarchy with consistent heading sizes

## Accessibility Requirements
- WCAG 2.1 AA compliance
- Minimum 4.5:1 color contrast ratio
- Keyboard navigation support
- Screen reader compatibility
- Focus indicators on all interactive elements
